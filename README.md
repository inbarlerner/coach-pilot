# פיילוט קואצ׳ינג — ניתוח סרטונים על ידי מאמנים

גרסת ניסיון עובדת: מתאמן מעלה סרטון, בוחר מאמן מאושר ומקבל ניתוח בטקסט, קול או וידאו, עם הודעות המשך לפי מדיניות המאמן.

## מבנה

| תיקייה | מה יש בה |
|---|---|
| `public/` | האתר עצמו (HTML, CSS, JavaScript ללא שלב בנייה). ממשק בעברית, RTL, שחור־לבן. |
| `functions/api/` | פונקציות שרת של Cloudflare Pages: קישורים חתומים וזמניים להעלאה ולצפייה בקבצים, אחרי בדיקת הרשאה במסד הנתונים. |
| `supabase/` | סכמת מסד הנתונים, הרשאות (RLS), כללי עסק, משימה מתוזמנת לפקיעת זמן, והגדרת מנהל ראשון. |
| `tests/` | בדיקות: מסד נתונים (מסלול 1–12), חתימות קבצים, פונקציות שרת, ובדיקת ממשק מלאה בדפדפן. |

## שירותים

- **Supabase** — התחברות (מייל וסיסמה, שחזור סיסמה), מסד נתונים Postgres עם הרשאות בצד השרת, ומשימה מתוזמנת (pg_cron) שמסגירה בקשות שזמנן עבר גם כשאף אחד לא מחובר.
- **Cloudflare R2** — אחסון הסרטונים וקבצי התגובה. הדלי פרטי; כל צפייה או העלאה עוברת דרך קישור חתום שתקף לזמן קצר, ורק אחרי שהמסד אישר שלמשתמש מותר.
- **Cloudflare Pages** — אירוח האתר ופונקציות השרת.

## משתני סביבה (Cloudflare Pages → Settings → Variables and Secrets)

| שם | ערך |
|---|---|
| `SUPABASE_URL` | כתובת הפרויקט ב־Supabase |
| `SUPABASE_PUBLISHABLE_KEY` | המפתח הציבורי (`sb_publishable_...`) |
| `R2_ACCOUNT_ID` | מזהה החשבון ב־Cloudflare |
| `R2_ACCESS_KEY_ID` | מפתח גישה ל־R2 (סוד) |
| `R2_SECRET_ACCESS_KEY` | מפתח סודי ל־R2 (סוד) |
| `R2_BUCKET` | שם הדלי, למשל `coach-media` |

אין צורך במפתח השירות (service role) של Supabase — כל פעולה רצה בשם המשתמש המחובר, והמסד מחליט מה מותר.

## מגבלות פיילוט

סרטון: עד 200MB, ‏MP4 / MOV / WebM. קובץ קול: עד 50MB. וידאו תגובה: עד 200MB. המגבלות נאכפות בשרת (הגודל והסוג חלק מהחתימה).

## בדיקות

```
node tests/sigv4.test.mjs           # חתימת S3 מול וקטור הייחוס של AWS
node tests/functions.test.mjs       # פונקציות שרת והרשאות
psql -f tests/supabase_stub.sql -f supabase/001_schema.sql -f tests/acceptance.sql   # מסלול 1–12 במסד
python3 tests/e2e/acceptance_ui.py  # ממשק מלא בדפדפן מול Supabase Auth + PostgREST מקומיים (ראו tests/e2e/server.mjs)
```

כלל עסקי לתשלום עתידי: חיוב רק בשליחת ניתוח (`send_analysis`). לא בבקשה, בטיוטה, בסירוב או בפקיעת זמן. תנאי המאמן נשמרים בכל בקשה (`terms`).
